# AppRideBoard
## LEAFLET - BIBLIOTECA USADA PARA MOSTRAR EL MAPA
La documentación usada para crear el mapa se encuentra en https://leafletjs.com/examples/quick-start/ y funciona creando un objeto mapa con latitud y longitud del lugar que deseamos.

## Nominatim - BIBLIOTECA USADA PARA LA CONVERSIÓN A COORDENADAS
Sirve par y convertir nombres de lugares en coordenadas geográficas y viceversa utilizando la base de datos de OpenStreetMap.
